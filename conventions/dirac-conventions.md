# Dirac 規約の対応表と変換の辞書

> **位置づけ**: 同じ Minkowski 計量 (−,+,+,+) でも、 Dirac 行列の Clifford 代数の符号が教科書で割れる (Srednicki と Weinberg は計量が同じで Clifford が逆)。 共同研究の各 project は自分の repo の記号の規約の節で「本 project はこの表のどの行か」 を宣言し、 式を文献から写すときは本 doc の辞書を通す。 本 doc は公開層にある対応表そのもので、 **どの行を選ぶかは project の側が決める** (本 doc は既定を持たない)。

教科書の規約を表にするときの規律 (各セルは宣言の引用か推定の明記) は [`physics-notes.md`](physics-notes.md) 第 2 節。 検算の規律 (一致合わせは検証でない) は [`scientific-computing.md#verify-independent-derivation`](scientific-computing.md#verify-independent-derivation)。

## <a id="dictionary"></a>2. 変換の辞書

記号: 添字 P / S / W = Peskin–Schroeder / Srednicki / Weinberg。 上添字の p^μ, x^μ は 3 冊で共通にとり、 下添字は各本の計量で下げる。

**Srednicki ↔ Weinberg** (計量が同じ、 Clifford が逆):

- γ_W^μ = −i γ_S^μ。 印字された明示表現がこの関係をそのまま満たす ((5.4.17) = (36.7) の −i 倍)。
- 帰結: {γ_W,γ_W} = −{γ_S,γ_S} = 2η。 (γ⁰_W)² = −1。 β_W = iγ⁰_W = γ⁰_S = β_S なので **ψ̄ は共通**。
- 自由ラグランジアンが一致する: −ψ̄(γ_W^μ∂_μ + m)ψ = −ψ̄(−iγ_S^μ∂_μ + m)ψ = iψ̄γ_S^μ∂_μψ − mψ̄ψ。 Dirac 方程式も (γ_W∂ + m) = (−iγ_S∂ + m)。
- 伝播関数の分子: −i(−iq̸_W + m) = −i(−q̸_S + m)。 分母と指数は計量が同じなので同じ。
- 運動量空間のスピノル: (iγ_W^μp_μ + m)u = 0 ⇔ (γ_S^μp_μ + m)u = 0。

**Peskin–Schroeder ↔ Srednicki** (Clifford の形は同じ ±2g、 計量が逆):

- γ_P^μ = γ_S^μ (同じ数値行列)、 g_P = −g_S。 添字を下げた量だけ符号が反転する: p^P_μ = −p^S_μ、 x^P_μ = −x^S_μ、 p_P² = −p_S²、 p_P·x = −p_S·x、 p̸_P = −p̸_S。 ∂_μ = ∂/∂x^μ と上添字の γ^μ は共通。
- ψ̄ は共通 (γ⁰_P = β_S)。 自由ラグランジアンは**記号ごと同一** (上添字 γ と下添字 ∂ の縮約なので符号も変わらない): ψ̄(iγ^μ∂_μ − m)ψ。 Dirac 方程式 (3.31) と (36.11) も記号ごと同一 (全体の符号だけ)。
- 伝播関数: i(p̸_P+m)/(p_P²−m²+iε) · e^{−ip_P·x} = −i(−p̸_S+m)/(p_S²+m²−iε) · e^{ip_S·x} (分子・分母・指数がそれぞれ符号で読み替わり、 全体は同じ)。
- **写すときに変わるのは添字を下げた量の符号だけ**: p_μ、 x_μ、 p²、 p·x、 p̸、 ∂² = ∂_μ∂^μ。 「mostly minus の式を mostly plus に写す」 とは、 これらの符号を変えることであって γ 行列を変えることではない。

**Peskin–Schroeder ↔ Weinberg** = 上の 2 つの合成: γ_W^μ = −iγ_P^μ、 η_W = −g_P。

## <a id="numerical-check"></a>3. 数値検算

[`scripts/check-dirac-conventions.py`](../scripts/check-dirac-conventions.py) が、 3 冊の印字された明示表現から表の各行と辞書の各式を検算する (numpy、 乱数は seed 固定)。 検査の一覧は script の冒頭。 負の対照 (辞書の符号を 1 つ誤らせる) で落ちることも同じ実行で確かめる。

```bash
python3 scripts/check-dirac-conventions.py
```

期待する終わり方 = `--- 結果: 本検査の失敗 0 件 / 負の対照で落ちた検査 N 件 ---` (N > 0)。 表を直したら script も同じ commit で直す (表の式番号は script のコメントにも写してある)。

## <a id="rule"></a>4. 規則

1. **project ごとに、 使う行を repo の記号の規約の節で宣言する** (「本 project = 本表の Weinberg の行」 のように、 本 doc の GitHub URL とともに 1 行)。 計量だけ宣言して Clifford を書かない原稿は、 Srednicki と Weinberg のどちらとも整合するので、 共同研究者は決められない。 例外 (別の規約の付録・派生 note) があれば同じ行に書く。
2. **規約の違う文献から式を記号のまま写さない**。 写すなら §2 の辞書を通し、 写した式を自分の規約で 1 回導出し直す ([`scientific-computing.md#verify-independent-derivation`](scientific-computing.md#verify-independent-derivation))。 γ 行列が同じ数値でも、 添字を下げた量 (p̸ や p²) の符号が変わる (Peskin–Schroeder ↔ Srednicki)。 計量が同じでも γ 行列が −i 倍になる (Srednicki ↔ Weinberg)。
3. **表に行や列を足すときは、 セルごとに宣言の式番号を添える** ([`physics-notes.md`](physics-notes.md) 第 2 節)。 既存の自前の対応表に式番号が無ければ、 それは下書きであって引用の根拠にならない。 書籍版と arXiv 版で番号が違う本は版を書く。

## <a id="unverified"></a>5. 未照合・注意

- Hermite 性の 3 セルは明示表現からの推定。 本文に Hermite 性を宣言する式 (例: (γ^μ)† = γ⁰γ^μγ⁰ の形) があるかは Peskin–Schroeder と Srednicki で未照合。 Weinberg は (5.4.30) が宣言。
- Weinberg の ⟨Tψψ̄⟩ は 3 式と β² = 1 からの導出で、 その形で印字された式は見ていない。
- Srednicki の arXiv 版 (hep-th/0409035, 0409036) の式番号は書籍版と違う (実測: Clifford の式が別の番号)。 本表は書籍版。
- スピノルの規格化 (ūu の値、 (2π) の因子、 スピン和) は本表の範囲外。 必要なら同じ規律 (式番号つき) で行を足す。
