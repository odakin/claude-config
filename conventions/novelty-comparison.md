# 新規性の比較 — 比べる文を固定し、 判定の語を 5 つにする

<a id="purpose"></a>**目的**: 原稿の主張が先行研究に対して新しいか、 先行研究から導けるかを論じるときに、 AI が「既知」「導ける」「新しい」 を甘く言うのを止める。 甘さは両方の向きに出る。 **先行研究に甘い誤り** = 先行研究が実際に示した以上のものを先行研究に帰す (根拠が足りないのに「先行研究だけから出る」 と言う)。 **自分の論文に甘い誤り** = 自分の主張を、 示した範囲より広く言う (「どの場合にも成り立つ」「初めて」)。 この文書は両方を対象にする。

**持つもの**: 比べ方の規則、 判定の語、 表。 物理・数理の論文と研究ノート、 その議論、 査読・審査に当てる。 隣の文書が持つもの: 文献の探し方と読み方 = [`manuscript-value-triage.md#prior-work-check`](manuscript-value-triage.md#prior-work-check) と [`web-tools.md#literature-search-apis`](web-tools.md#literature-search-apis) / 自分が辿り着いた構造を文献で引く手順 = [`physics-verification-cycle.md#prior-art-by-operation`](../../ai-collaboration/conventions/physics-verification-cycle.md#prior-art-by-operation) / 投稿先の型に対して新規性が足りるか = [`paper-audit.md#novelty-calibrated-to-venue`](paper-audit.md#novelty-calibrated-to-venue) / 面白さ・重要さの読み = [`manuscript-value-triage.md`](manuscript-value-triage.md)。

## <a id="why-verdicts-drift"></a>なぜ判定が動くか

実測: 事実の認識は一致しているのに、 同じ主張に付く判定の語が議論のたびに変わり、 問い返されると逆の語に替わった。 原因は 3 つあった。

1. **比べる文が決まっていない**。 主張の一部や弱めた版に付けた判定を、 主張の全体の判定として言う。
2. **一般論と具体的な構成を混ぜて比べている**。 一般的な枠組みが既知であることを理由に、 具体的な構成まで既出と言う。
3. **「数行で出る」 を物差しにしている**。 答えを知った後なら、 何でも数行で出る。

物差しが無いと、 判定は最後に押した人の方へ動く。 下の規則は、 判定を表の中身 (頁・段の出どころ・反例) に結び、 中身が変わらなければ判定が変わらないようにする。

## <a id="rules"></a>規則

1. <a id="fix-the-statement"></a>**比べるのは、 論文が述べるとおりの主張の全体。** 主張を、 対象・仮定・結論・成り立つ範囲まで書いた文 (か式) として書き出して固定する。 成り立つ範囲が自明でないこと (対象が存在する、 式が意味を持つ、 級数が収束する、 集合が空でない) までが主張に含まれる。 先行研究の側も、 どの文献の、 どの版の、 どの頁のどの文・式かを固定する。 条件つきの版・形式的な版・特別な場合のような弱めた文を比べるなら、 何を外したか (どの仮定・範囲・保証) を書き、 その判定を元の主張の判定として言わない。
   - 頁と式番号の確かめ方、 読んだ深さ (本文 / 要旨 / 二次資料 / 未取得) の書き方 = [`physics-verification-cycle.md#literature-fetch-and-reading-depth`](../../ai-collaboration/conventions/physics-verification-cycle.md#literature-fetch-and-reading-depth)、 [`writing-discipline.md#earlier-work-by-contribution`](writing-discipline.md#earlier-work-by-contribution)。
   - <a id="special-case-check-is-not-the-whole"></a>**特別な場合で確かめた一致を、 主張の全体の判定として言わない。** 確かめた場合 (次元・粒子数・極限・パラメータの範囲) を表に書き、 確かめていない場合は別の行にして「未判定」 に置く。 合成の例: 主張が 3 次元の中心力の束縛運動についてのものなら、 1 次元の運動で先行研究の式と一致したことは 1 次元の行の判定で、 3 次元の行は別に判定する。
   - 先行研究の仮定を結果として引かない = [`manuscript-value-triage.md#assumption-cited-as-result`](manuscript-value-triage.md#assumption-cited-as-result)。 総説の要約は定理の条件を落とすことがある = [`#review-paraphrase-drops-condition`](manuscript-value-triage.md#review-paraphrase-drops-condition)。
2. <a id="three-kinds-of-prior-content"></a>**先行研究が与えるものを 3 種に分ける。**
   - **中身の保証された結果**: 仮定の下で結論が成り立ち、 その結論の当てはまる対象が実際に在ることまで示されている定理・計算。
   - **具体例**: 特定の対象について実行された計算・構成。
   - **形式的な式**: 両辺が意味を持つ所で成り立つ、 までしか言っていない式。 意味を持つ所が自明なもののほかに在るかは示されていない (例: 摂動の各次数の係数を与える漸化式は、 級数が収束することを与えない。 係数が階乗で増えれば、 収束するのは結合定数が 0 のときだけ)。

   「導ける」「既知」 と言えるのは、 前の 2 つに当たるときだけ。 形式的な式から言えるのは「両辺が意味を持てば成り立つ」 までで、 意味を持つことの保証は別の入力に数える。 見分け方 = その式の前後に、 存在・収束・定義される範囲・自明でないことの主張と、 その証明か計算が在るか。 無ければ形式的な式に置く。
3. <a id="compare-at-the-same-level"></a>**同じ階層どうしで比べる。** 一般の主張 (定理・一般式・存在の主張) は一般の主張と、 具体的な構成 (特定の系・模型・装置について実行した計算と、 それで計算・予測できるようになったこと) は具体的な構成と比べる。 一般論が既知でも、 具体的な構成が既出と言わない。 具体例が載っていても、 一般の結果が既知と言わない。 具体的な構成が既出だと言うなら、 同じ構成の先行例を示し、 仮定・存在の条件・定義される範囲・測る対象を 1 つずつ対応させる (記号や変数が違うなら写像を書く。 異議の述べ方 = [`manuscript-value-triage.md#general-framework-and-concrete-construction`](manuscript-value-triage.md#general-framework-and-concrete-construction))。
4. <a id="source-per-step"></a>**導出の各段に出どころを書く。** 「先行研究から出る」 と言うときは導出を書き、 段ごとに次の札のどれかを付ける。
   - **先行研究**: 文献と、 頁・式。 規則 2 のどの種類かも書く。
   - **教科書の事実**: 標準の数学・物理の事実 (どの本のどこか、 定理の名前)。
   - **我々の入力**: この論文が足す仮定・構成・確認 (こちらの対象が先行研究の条件をみたすことの確認を含む)・制限。

   札を付けられない段は「我々の入力」 か「未判定」 に置く。 「我々の入力」 の段が 1 つでもあれば、 判定は「先行研究だけから出る」 にならない。 導出を書かずに「出る」 と言わない。 参照 1 件ごとに「指す先が合っているか・主張を支えるか・参照先に無い前提を足しているか」 を見る形、 変数や出力の形が違う結果を操作の列で突き合わせる形 = [`physics-verification-cycle.md#compare-through-operations`](../../ai-collaboration/conventions/physics-verification-cycle.md#compare-through-operations) とその前の項。
5. <a id="counterexample-before-follows"></a>**「先行研究だけから出る」 と書く前に、 反例を探す。** 先行研究の仮定だけをみたす例で、 主張が偽になるか、 中身が空になるものを作ってみる。 作れたら「出ない」 とし、 欠けている仮定を名指す。 試していなければ「未判定」 で、 「出る」 と書けない。 同じ手を自分の論文の文にも当てる (「どの場合にも成り立つ」「常に」「〜だけである」 の類)。 手順 = [下の節](#counterexample-search)。
6. <a id="verdict-words"></a>**判定の語は次の 5 つだけを使う。 行数は物差しにしない。** 印刷されている / 先行研究だけから出る / 我々の入力を足せば出る / 新しい考えが要る / 未判定。 定義 = [下の節](#verdict-definitions)。 「数行で出る」「自明」「実質的に同じ」「ほぼ既知」 を判定に使わない。 導出が短いことは、 段の出どころを変えない。
7. <a id="adjectives-belong-to-author"></a>**形容詞は著者が付ける。** AI が出すのは、 表と、 見た範囲・見ていない範囲まで。 「新しい」「新規性が損なわれる」「主張が強すぎる」 の類の評価の語は、 AI の文に書かない。 「見つからなかった」 を「無い」 と言わない (言えるのは調べた範囲のこと = [`convention-design-principles.md#absence-channel-coverage`](../docs/convention-design-principles.md#absence-channel-coverage))。 判定を変えるのは、 表の中身 (頁、 段の出どころ、 反例) が変わったときだけで、 何が変わったかを記録する。 問い返されたら、 判定を替える前に、 表のどの欄が違うと言われたのかを確かめる。 査読・審査では、 評価の語を付けるのは評価を出す本人。
8. <a id="substitute-into-general-before-new"></a>**具体的な構成を新しいと言う前に、 先行研究の一般の式・構成に代入してみる。** 先行研究の一般の式・構成に自分の構成を代入できるなら、 代入を実行して、 得られる対象が、 先行研究に陽に印刷された対象 (下の 1 つ目の項の意味で) に等しくならないかを確かめる。 等しくなったら、 その対象を新しいと書かず、 「既知の対象を、 この構成で実現した」 と書く。 表では、 対象の行を「印刷されている」 にし (比べた先の頁・式と、 等しいことを示す写像を添える)、 実現の仕方を別の行にして判定する。 代入できるのに実行していなければ、 対象の行は「未判定」。 代入できるなら必ず実行する。 実行して、 陽に印刷された対象と一致しなければ、 この確かめでは行を動かさない。
   - <a id="printed-object-definition"></a>**「印刷された対象」 と数えるもの。** 先行研究が、 こちらの構成に依らずに、 主張と同じ詳しさ (陽な式、 定義される範囲、 値) で書き下している対象。 対象の存在や一意性の証明と、 入力を残したままの一般の式は、 その対象を印刷したことにならない。 一般の式に代入して得た対象を、 その一般の式が印刷されていることを理由に「印刷されている」 にしない (規則 3 が退ける読み方と同じ)。
   - <a id="existence-only-prior"></a>**先行研究が存在しか示していない対象を、 こちらが陽に構成・計算したとき。** 陽な形の行は「印刷されている」 にせず、 ほかの規則 (導出の段ごとの出どころ・反例探し・決める順) で判定し、 「足すもの・要る考え」 の欄に陽な構成を書く。 論文が存在そのものも言うなら、 その文は別の行にして、 先行研究の存在の文と比べる (規則 1・3)。
   - <a id="one-way-check"></a>**この確かめは片方向にだけ使う。** 陽に印刷された対象と一致したときにだけ行を動かす。 一致しないことや、 先行研究に陽な対象が無いことは、 どちらの向き (新しい側・新しくない側) の根拠にもしない = 行を、 決める順の上の語 (先行研究の側) にも下の語 (自分の論文の側) にも動かさず、 ほかの規則で判定する。 これは代入を実行した後の扱いで、 陽な対象が無いと見込んでも、 代入できるなら実行する (何と比べるかは、 代入して対象の形が出てから分かることが多い)。 代入できるのに実行していない行が「未判定」 なのは、 済ませていない段があるからで (決める順の (6))、 陽な対象が無いことで行を動かしたのではない。

   規則 3 と対になる検査で、 規則 3 は一般論が既知であることから具体的な構成の既出を言わず ([`manuscript-value-triage.md#general-framework-and-concrete-construction`](manuscript-value-triage.md#general-framework-and-concrete-construction))、 この規則は構成が具体的であることから対象が新しいと言わない。 式の導出に同じ手を当てる形 = [`manuscript-value-triage.md#specialize-nearest-general-formula`](manuscript-value-triage.md#specialize-nearest-general-formula)。

## <a id="verdict-definitions"></a>5 つの判定の語

| 語 | 使える条件 | 添えるもの |
|---|---|---|
| **印刷されている** | 固定した主張の文 (対象・仮定・結論・成り立つ範囲) が、 先行研究のその頁に同じ中身で書かれている。 記号や変数が違うなら、 写像を書いて確かめた後に使う。 弱い文や別の対象の文が書かれているだけなら使わない。 対象の存在や一意性の証明と、 入力を残したままの一般の式は、 その対象を同じ中身で書いたことにならない ([規則 8 の項](#printed-object-definition)) | 文献・版・頁・式番号、 読んだ深さ |
| **先行研究だけから出る** | 導出の全部の段の出どころが、 先行研究 (中身の保証された結果か具体例) と教科書の事実だけ。 かつ、 反例を探して見つからなかった。 この語の意味は「反例を探したが見つからない」 までで、 「出ることを証明した」 ではない | 導出と段ごとの出どころ、 反例探しで試した範囲 |
| **我々の入力を足せば出る** | 導出に「我々の入力」 の段が要る。 または、 反例が作れて、 欠けている仮定が分かった | 足すものを 1 つずつ名指す |
| **新しい考えが要る** | 名指せる入力を先行研究の導出に足しても、 導出が閉じない (骨組みになる概念・構成・方法が先行研究に無い)。 最も近い先行の一般式に自分の場合を入れる試み ([`manuscript-value-triage.md#specialize-nearest-general-formula`](manuscript-value-triage.md#specialize-nearest-general-formula)) を済ませた後に使う | 要る考えを 1 文で、 試みた導出の範囲 |
| **未判定** | 文献を読めていない、 導出を書いていない、 反例を探していない、 最も近い一般式に入れる試みをしていない、 具体的な構成の行で、 先行研究の一般の式・構成に代入できるのに代入していない ([規則 8](#substitute-into-general-before-new))、 のどれか | 済んでいないもの |

**決める順**: (1) 主張の文を固定し、 先行研究の頁に同じ文が在れば「印刷されている」。 (2) 無ければ導出を書く。 (3) 全部の段が先行研究と教科書の事実なら反例を探し、 見つからなければ「先行研究だけから出る」。 (4) 「我々の入力」 の段が在るか、 反例が作れたら「我々の入力を足せば出る」。 (5) 入力を足しても閉じなければ「新しい考えが要る」。 (6) 途中の段を済ませていなければ「未判定」。 上の語ほど先行研究の側に、 下の語ほど自分の論文の側に倒れる。 どちらの向きにも、 条件を確かめずに 1 段ずらさない。

## <a id="counterexample-search"></a>反例探しの手順

1. **先行研究の仮定を書き出す。** その頁が実際に課している仮定だけを並べる。 自分の論文の仮定を混ぜない。
2. **その仮定だけをみたす例を、 単純なものから作る。**
   - 自分の論文が足している仮定を 1 つずつ外した例 (最も効く。 外しても先行研究の仮定はみたしたままにする)。
   - 自明な場合 (零・空・定数・相互作用の無い場合)。
   - 極端な場合 (境界・退化・無限大)。
3. **各例で、 固定した主張がどうなるかを見る。** (a) 偽になる。 (b) 中身が空になる = 主張の対象が存在しない、 式の両辺が意味を持つ対象が自明なものだけになる、 級数が収束しない。 (b) も反例に数える。 条件つきの文が真のままでも、 論文の主張は成り立つ範囲が自明でないことまで含む (規則 1)。
4. **作れたら**: 判定を「先行研究だけから出る」 にしない。 その例を締め出す条件 (欠けている仮定) を名指し、 表の「足すもの」 に書く。 例は表に残す (構成を 1〜2 行。 検算したなら、 その script の場所)。
5. **作れなかったら**: 「先行研究だけから出る (反例を探したが見つからない)」 と書き、 試した例の一覧 (何を外したか) を添える。 「出る」 とだけ書かない。
6. **試していなければ**「未判定」。
7. **自分の論文の文に当てるとき**: 「どの場合にも」「常に」「一意に」「〜だけである」 の類の文について、 自分の仮定だけをみたす例で文が偽になるものを同じ手で探す。 作れたら、 欠けている仮定を足した文を案として表に書く。 原稿の文を替えるのは著者 ([`manuscript-claim-ownership.md#rule`](manuscript-claim-ownership.md#rule))。 強い言明の検査 = [`paper-audit.md#claim-strength-three-tests`](paper-audit.md#claim-strength-three-tests)、 式の直後の文が式より広く言う型 = [`paper-audit.md#post-formula-generalization-traps`](paper-audit.md#post-formula-generalization-traps)。

作った反例は、 先行研究の仮定を本当にみたすか、 主張を本当に破るかを、 作った本人でない目か機械で確かめる ([`physics-verification-cycle.md#independent-second-eye`](../../ai-collaboration/conventions/physics-verification-cycle.md#independent-second-eye))。

## <a id="synthetic-example"></a>合成の例

実在の論文ではない。 題材は初等力学で、 先行研究の役をするのは合成の教科書 X だけにする。 現実にはどの行も古くから知られていて、 判定は X に対するもの (見た範囲 = X だけ)。 式は数値で確かめてある ([`scripts/check-novelty-example.py`](../scripts/check-novelty-example.py)。 確かめるのは式で、 判定の語は確かめない。 例の式を直したら、 この script の対応する項目も直す)。 規則・判定の語の表・検収の段の文を直したら、 この例の行に 1 つずつ当て直して、 判定が変わらないか (変わるならどちらが正しいか) を読む (script は判定の語を見ない。 実測: 規則は「その対象」 と書いていた確かめを、 検収の段では行の全部に掛かる文で足し、 例の正しい行が差し戻しになるのを検収の側が見つけた)。

**X が与えるもの**: (a) 結果 = 1 次元の保存力の下で、 エネルギー E の隣り合う転回点 x₁ < x₂ が在り (その間で V(x) < E)、 どちらの転回点でも V の傾きが零でなければ、 その間の運動は周期的で、 周期は T(E) = √(2m) ∫ dx / √(E − V(x)) (x₁ から x₂ まで) 〔X の式 (1)。 以下、 この 2 つの条件を「式 (1) の条件」 と呼ぶ。 転回点が V の極大に当たると、 周期は有限でなくなる〕。 (b) 具体例 = 調和振動子 V = kx²/2 の周期 T = 2π√(m/k) 〔X の例題 1〕。 (c) 存在だけを言う結果 = 式 (1) の条件をみたすエネルギーの区間で周期 T(E) が連続なら、 その区間で周期がとる 2 つの値の間のどの値 T₀ にも、 周期がちょうど T₀ になる E が在る 〔X の命題 2。 その E の式は書いていない〕。

| # | 我々の主張 | 階層 | 先行研究が与えるもの | 判定 | 足すもの・要る考え |
|---|---|---|---|---|---|
| 1 | 式 (1) の条件をみたす 1 次元の運動の周期は式 (1) で与えられる | 一般 | X の式 (1)、 結果 | 印刷されている | |
| 2 | 式 (1) の条件をみたす運動の周期は、 V(x) を V(−x) に替えても変わらない | 一般 | X の式 (1)、 結果。 例題 1 が、 対象が空でないことの具体例 | 先行研究だけから出る (反例を探したが見つからない。 試した = 調和振動子、 左右非対称な井戸) | |
| 3 | V = −V₀/cosh²(x/a) では、 −V₀ < E < 0 のどの E でも運動は周期的で、 T = πa√(2m/\|E\|) | 具体 | 一般の側 = X の式 (1) (式 (1) の条件つき)。 具体の側 = この V の例は X に無い | 我々の入力を足せば出る | この V が −V₀ < E < 0 の各 E で式 (1) の条件をみたすことの確認 (転回点が 2 つ在り、 そこで V の傾きが零でない) |
| 4 | 左右対称なポテンシャルで、 周期が E に依らないものは調和振動子だけである | 一般 | X の式 (1) は V から T を出す向きだけを与える | 新しい考えが要る | 周期の関数から対称なポテンシャルを決める、 逆向きの議論。 試みた = 式 (1) に対称性を課した直接の評価 (個々の V の周期は出るが、 「だけ」 は出ない) |

- **行 2 の導出**: 式 (1) で x を −x に置き換える。 出どころ = X の式 (1) と、 教科書の事実 (積分の変数変換)。 「我々の入力」 の段は無い。
- **行 3 の導出**: 転回点 x = ±a arcosh√(V₀/|E|) は 0 でなく、 そこで V の傾きは零でない 〔我々の入力 = この V の性質の確認〕 → 式 (1) 〔X〕 → u = sinh(x/a) と置いて積分 〔教科書の事実〕。 **反例探し**: X の枠組みの仮定 (1 次元の保存力) だけをみたす V = −Fx (一様な力) では、 転回点が 1 つしか無く、 周期運動が無い。 式 (1) の条件は対象ごとに確かめるもので、 式 (1) だけからは「この V の運動が周期的」 が出ない。 だから行 3 を「先行研究だけから出る」 と書かない。 X に一般式が印刷されていることから、 行 3 を「印刷されている」「既出」 とも書かない (規則 3: X に載る具体例は調和振動子だけ)。 規則 8 の代入 (この V を X の式 (1) に入れる) は上の導出そのもので、 得た T は E に依るので、 X に陽に印刷された周期 (例題 1 の、 E に依らない周期) と等しくならない。 この確かめでは行を動かさない (片方向の項)。 導出が数行で済むことは判定に使わない (規則 6)。
- **行 4 は、 自分の文に反例探しを当てた後の文**: 最初の文は「周期が E に依らないポテンシャルは調和振動子だけである」 だった。 自分の仮定だけをみたす例 V = Ax² + B/x² (x > 0、 A・B > 0) は、 周期が E に依らない。 最初の文は偽で、 欠けていた仮定は左右対称。 直した文を案として行 4 に書いた (原稿の文を替えるのは著者)。
- **代入して既知の対象になる例 (規則 8)**: 論文が「周期がエネルギーに依らない運動を与えるポテンシャルを構成した」 と書き、 構成が V = k(x − c)²/2 + V₁ (平行移動した放物線) だったとする。 E > V₁ で式 (1) の条件をみたし、 式 (1) に代入すると周期は T = 2π√(m/k) で、 X の例題 1 に印刷された周期と同じ関数になる (写像 = x を x − c に、 E を E − V₁ に置き換える)。 得られた対象は印刷されている。 書けるのは「例題 1 の周期を、 平行移動した放物線で実現した」 まで。
- **先行研究が存在しか示していない例 (規則 8 の項)**: 論文が「V = −V₀/cosh²(x/a) で、 T₀ > πa√(2m/V₀) なら、 周期が T₀ になるエネルギーは E = −2π²ma²/T₀²」 と書いたとする。 読み違い = 「X の命題 2 が在ると言う E に、 この V を当てただけだから、 対象は印刷されている」。 命題 2 は E を書き下していないので、 X にこの E と比べる陽な対象は無い。 陽な形の行は「印刷されている」 にせず、 導出で判定する: 行 3 の周期の式 〔X の式 (1) と、 我々の入力 = この V が式 (1) の条件をみたすことの確認〕 → T(E) = T₀ を E について解く 〔教科書の事実〕。 判定は「我々の入力を足せば出る」 で、 足すもの = 行 3 の条件の確認と、 それを解いた陽な E。 X に陽な E が無いことは、 この行を下の語へ動かす根拠にもしない (片方向の項)。 陽な E が無いと見込んでも、 この V を X の式 (1) に入れる代入はする (しなければ、 この行は「未判定」)。 ここでは代入が導出の 1 段目で、 得た対象 (行 3 の周期と、 それを解いた E) は X に陽に印刷された対象 (例題 1 の周期) と一致しないので、 この確かめでは行を動かさない。 判定を決めたのは導出の段の出どころ。 論文が「周期が T₀ になる E が在る」 とも言うなら、 それは別の行にして命題 2 の文と比べる (この V で T(E) が連続で、 T₀ を挟む値をとることの確認は我々の入力)。
- **形容詞の置き場所**: 行 3 と行 4 を論文の新しい結果と呼ぶかは、 著者が決める。 AI の文は上の表までにする。

## <a id="review-side"></a>検収の側の段

新規性の判定 (既知・導ける・新しい、 のどれかを言う文) を含む提出を受け取る側は、 中身の検収の前に次の 2 つをする。

1. **形を見る。** 次のどれかが欠けていれば差し戻す:
   - 比べる文が固定されている (規則 1。 主張の全体と先行研究の頁・式。 弱めた文の判定を元の主張に付けていない)
   - 階層が書いてあり、 同じ階層どうしで比べている (規則 3)
   - 「出る」 と言う行に、 導出と段ごとの出どころが在る (規則 4)
   - 具体的な対象の陽な形 (式・定義される範囲・値) を言う行を「印刷されている」 にしたなら、 比べた先の頁・式が、 先行研究が陽に書き下したその対象を指している (その対象の存在の証明や、 入力を残した一般の式を指していない。 [規則 8 の項](#printed-object-definition))。 一般の主張を一般の式と比べた行と、 存在の文を存在の文と比べた行には、 この確かめを当てない (規則 3 と [規則 8 の項](#existence-only-prior))。
   - 具体的な構成の行 (表の階層が「具体」。 規則 3) では、 先行研究の一般の式・構成への代入 ([規則 8](#substitute-into-general-before-new)) が済んでいるかを見る。 次の 3 つのどれかなら通り、 どれでもなければ差し戻す: (a) 代入の結果が書いてある / (b) 代入できる先 (一般の式・構成) が見た範囲に無い、 と書いてある / (c) (a) も (b) も無く、 判定が「未判定」 になっている。 (c) が無いと、 代入していないので正しく「未判定」 にした行まで差し戻しに読める。
2. **「先行研究だけから出る」 の行ごとに、 自分でも反例を 1 回探す。** 提出が試した範囲の外の例を 1 つ以上作ってみる ([手順](#counterexample-search))。 作れたら、 その例を添えて差し戻す。 作れなければ、 試した例を受け取りの記録に書く。 数値の検算が通っていても、 この段は省かない: 検算は式を確かめるが、 式に添えた条件の文は確かめない (実測: この文書の合成の例は式の数値が全部合っていたのに、 教科書役の結果の文に条件が 1 つ欠けていて、 検収の側が反例を作って見つけた)。

## <a id="adversarial-pair-before-submission"></a>投稿前の 2 体の立証

投稿前に、 主結果ごとに次の 2 つを別の AI (別の session。 できれば別の vendor) に書かせる。 日々の議論には付けない。

- **「先行研究だけから出る」 を立証する側**: 導出を、 段ごとの出どころつきで最後まで書く。
- **「出ない」 を立証する側**: 先行研究の仮定だけをみたす反例を作るか、 欠けている仮定を名指す。

渡すのは、 固定した主張の文と、 先行研究の写しと頁の指定。 どちらの側にも相手の結論と、 依頼する側の見立てを渡さない (隔離の手順 = [`cold-eyes-isolation.md#spec-leakage`](../../ai-collaboration/conventions/cold-eyes-isolation.md#spec-leakage))。 検収の側は 2 つの表を欄ごとに突き合わせ、 食い違い (ある段の出どころ、 反例が先行研究の仮定をみたすか) を、 原典の頁に戻って決める。 決まらなければ「未判定」 のまま著者に出す。 投稿前のほかの検査 = [`paper-audit.md`](paper-audit.md)。

## <a id="residual-weakness"></a>残る弱点

- **反例探しは、 探す側の腕に依る。** 見つからなかったことは、 無いことの証明にならない。 だから判定の語を「出る」 でなく「反例を探したが見つからない (試した範囲)」 までにし、 検収の側の探し直しを置いている。
- **同じ model は同じ例を見落とす。** 立証の 2 体と検収の側が同じ見落としをしうる。 投稿前の 2 体に別の vendor を入れるのはこのため。
- **判定の語と形容詞を見張る機械の検査は無い。** 守るのは書く側と検収の側。
- **「先行研究だけから出る」 と「我々の入力を足せば出る」 の境は、 段の札の付け方で決まる。** 標準の計算の段は教科書の事実に、 対象の指定と、 その対象が先行研究の条件をみたすことの確認は我々の入力に数える (規則 4)。 どちらに数えるかに判断が残る段は、 札と理由を表に書いて、 読む人が付け直せるようにする。
- **規則 8 の「同じ詳しさ」 と、 比べる先をどの対象にするかには読みの幅が残る。** どこまで書き下してあれば陽に印刷されたと数えるか (式は在るが定義される範囲が書いていない、 値の表だけが在る) と、 先行研究に陽な対象が幾つか在るとき、 代入して得た対象と同じ種類のどれを比べる先にするかは、 読む人の判断に依る。 式は在るが範囲が無ければ、 範囲を足すものに数える読み方がある。 だから表の代入の行に比べた先の頁・式を書かせ、 検収の側の形の確かめで見る。
- **代入できるかの判断にも読みの幅が残る。** 自分の構成が先行研究の一般の式・構成の仮定に当たるか、 どの一般の式・構成を代入する先にするかは、 読む人の判断に依る。 検収の側の形の確かめは「代入できる先が見た範囲に無い」 と書いてある行を通すので、 その判断の誤りは形では見えない。 だから表に見た範囲を書かせ、 読む人が代入できる先を探し直せるようにする。
- **見た範囲の外に、 同じ文が印刷されていることがある。** 判定はどれも見た範囲に対するもので、 表に見た範囲と見ていない範囲を書く。
