# SVG のコードで絵を描く

ロゴ・アイコン・挿絵を、画像ファイルでなく SVG のコードで描いてページに埋め込む場面。

## <a id="render-and-look"></a>描いたらラスタにして見る

- 座標を頭の中で組み立てただけの絵は、ほぼ必ず崩れている（部品が枠からはみ出す、比率が違う物に見える、実測）。
  **描く → PNG にして目で見る → 直す**を回す
- macOS で `rsvg-convert` が無ければ `qlmanage -t -s 1080 -o <dir> file.svg` で PNG が得られる
- 1 部品だけを大きく、回転や縮小を外して描き出すと、形の問題が見つけやすい
- 並べて使う絵（例: 3 つ並びのマーク）は、並べた状態と、実際の表示サイズ（ヘッダーで幅 300 px 前後など）の両方で見る

## <a id="distinguishing-features"></a>何の絵か分かる決め手は、その物にしか無い特徴

- 汎用の形（例: ギターの絵文字の輪郭）では、似た別の物（ベースとギター）を区別できない。
  区別の決め手になる特徴を**実物から**取る。楽器なら型ごとのボディの輪郭・ヘッドの形・ペグの数と並び・ピックガードの形・
  金属部品の位置、弦の本数
- 首とボディの長さの比のような**比率**が違うだけで、別の物に見える（首が短いベースはギターに見える、実測）
- 料理は「記号としての皿」だと美味しそうに見えない（実測）。**実物の盛り付け**（皿の色、主役と付け合わせの配置、
  色の対比）と、照り・油の縁・湯気のような質感の手がかりを入れる
- 小さく表示すると細部（弦・粒）は潰れる。**輪郭と色の塊で分かる**ようにし、細部は大きい表示のときのおまけと考える

## <a id="scope-ids"></a>同じ SVG を複数埋め込むときは id に接頭辞を付ける

グラデーション・クリップ・フィルタの定義（`<defs>` の `id`）を持つ SVG を、1 ページに何枚も直接埋め込むと id が重複する。
ブラウザは最初に見つけた定義を使うので、**その定義が非表示（`display:none`）の SVG の中にあると、参照している絵が描かれない**。
埋め込むたびに、`id="x"` と `url(#x)` を同じ接頭辞付きの名前に置き換える。

## <a id="style-variants"></a>画風の案を出すとき

- 同じ形の定義を共有して、塗り方だけを変える（線だけ／白フチと影のステッカー／暗い地に光る線、など）と、
  案どうしの比較が形の差に邪魔されない
- 選ばれなかった案も消さずに残し、設定 1 行で切り替えられるようにしておくと、後から戻れる
