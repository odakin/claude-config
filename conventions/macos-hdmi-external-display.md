# macOS で HDMI 外部表示が認識されるのに映らないとき

外部画面の不調を「ミラーリング設定」の一語で扱わない。少なくとも次の層を分ける。

1. Mac が sink の EDID / hot-plug を検出したか。
2. macOS が現在の接続で何を表示するか確定したか。
3. Mac が出した信号を、ケーブル・変換器・AV スイッチャー・プロジェクターが最後まで運べるか。

「ディスプレイ」設定に名前が出たことは 1 の証拠にすぎず、3 の証拠ではない。

## <a id="external-display-fast-path"></a>最短の復旧手順

1. HDMI を接続したまま `fn` + `C` でコントロールセンターを開く。
2. 「画面ミラーリング」→接続先→「画面全体」を選ぶ。投影側に「メニューからミラーリングまたは拡張を選択」のような待機画面が出たときは、システム設定でなくこの経路を先に使う。
3. 「システム設定」→「ディスプレイ」で外部側を選び、「使用形態」を「内蔵ディスプレイをミラーリング」にする。
4. まだ黒い場合は、外部側に最適化し、`1920 x 1080`・`60 Hz`、HDR オフ（項目がある場合）にする。
5. 設定変更後も変わらなければ、HDMI を一度抜き差しして current connection を作り直す。

内蔵ディスプレイを選んだときの「Apple XDR Display」プリセットと「ProMotion」は内蔵パネル側の設定であり、この切り分けの入口ではない。
複数画面の接続中に `command` + 輝度を下げるキーを押すと、Apple の標準ショートカットでビデオミラーリングを切り替えられる。

## <a id="current-mode-vs-next-default"></a>現在の接続と次回の既定値を分ける

外部側を選んだときの「使用形態」が**現在の接続**を表す。一方、「テレビに接続されているとき」は**接続時の動作の既定値**で、それだけを現在の接続が開始済みという証拠にはしない。

「画面全体をミラーリング」を次回既定値にしていても、投影側が待機画面のままなら、コントロールセンターの「画面ミラーリング」から current connection を明示的に開始する。

## <a id="edid-intermediary-not-projector"></a>中継機器名は下流 projector の生存証明ではない

会場設備では、Mac が見る sink 名がプロジェクターでなく、EDID をエミュレートする HDMI 中継機器・音声分離器・スイッチャーの場合がある。たとえば IDK `UHDS-01` は HDMI audio embedder/de-embedder で、EDID エミュレート機能を持つ。macOS に `UHDS-01` が表示されても、分かるのは Mac からその中継機器までの hot-plug / EDID 経路が成立したことだけで、その先のスイッチャー入力・出力・プロジェクターまで映像が届いたとは限らない。

この状態でミラーリング・1080p・60 Hzまで成立しても投影されなければ、会場側へ次のように渡す。

> Mac は HDMI sink を認識し、1920 x 1080・60 Hz・ミラーリングで出力設定済みです。sink 名は中継機器なので、その先の入力選択・matrix routing・出力信号を確認してください。

## <a id="alternate-output-path"></a>本体 HDMI と USB-C→HDMI は別経路として試す

本体 HDMI で sink 名まで列挙されるのに映像が出ない場合、既知良好な USB-C→HDMI アダプタを試す。これは同じ端子形状の挿し直しではなく、USB-C / Thunderbolt 側と別の変換回路を通る独立した出力経路であり、HDMI handshake / EDID の相互運用性が変わる。

**実測:** Apple Silicon Mac → 業務用 AV 中継機器の経路で、本体 HDMI は sink の列挙・ミラーリング・1080p/60 Hz の設定まで成立したが下流に画像が出ず、USB-C→HDMI アダプタへ替えると画像が出た。これは「経路依存」を示すが、根因が Mac の HDMI PHY、ケーブル、中継機器、EDID 設定のどこかまでは同定しない。

講演・授業では、実際に成功した USB-C→HDMI アダプタと HDMI ケーブルを持参する。本体 HDMI が別のディスプレイで動くなら、本体端子の故障とは断定しない。

## <a id="external-display-preflight"></a>本番前の検収

- スライドを開けることではなく、**実際の出力経路で投影面に同じ画面が出ること**を検収する。
- 本体 HDMI と USB-C→HDMI の両方を一度試し、成功経路を記録する。
- sink 名が projector 自身か中継機器かを確認し、中継機器なら会場スタッフへ渡す文面を用意する。
- current mode がミラーリング、外部側が 1920 x 1080・60 Hzであることを接続中に確認する。
