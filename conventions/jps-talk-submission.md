# jps-talk-submission.md — 日本物理学会 (JPS) 大会 一般講演申込の form 機構と落とし穴

**Load this when**: JPS 年次大会 / 秋季大会の一般講演申込・概要集原稿提出の作業に入るとき (毎年 6-7 月頃に年次大会申込)。

制度個別値 (締切日・参加費額・領域キーワード番号表) は毎年変わり得るので**当年の募集要項・公式キーワード一覧が正本** (https://www.jps.or.jp/activities/meetings/ 配下)、 本 file は**制度横断で効く form 挙動・書式・落とし穴のみ**を持つ (= [erad-submission.md](erad-submission.md) と同じ思想)。 個人固有値 (会員番号・所属略称の定型・過去の選定) は各自の個人層に置く。

## 申込の全体像

- 申込は**会員マイページのみ** (https://member.jps.or.jp/a/login.do?act=init)。 締切は 14:00 JST 型 (= 深夜 23:59 でない) が通例 — 締切日当日の午後に始めると間に合わない。
- 講演申込と参加登録 (参加費支払) が**同一 form で一体**。 申込完了と同時に参加費の支払義務が発生する (講演取消でも返金なし)。
- **受付システムは学会本体と別ドメインの外部運営** (2026 実測: 自動返信の送信元 domain = `gakkai-web.net` 〔local part は大会別、 例 `jps_gakkai<西暦下2桁>@`〕、 各種手続ページ = `https://www.toyoag.co.jp/jps/index.html`)。 **`from:jps.or.jp` で mail 検索しても受理票は hit しない** — 大会名 or `from:gakkai-web.net` で検索する。 受理票は form の「登壇者メールアドレス」 欄に入れたアドレスに届く (= 会員登録メアドではない)。
- **登録完了で「登録番号」+「パスワード」 が発行される** (受理票画面 + 自動返信メール)。 修正・取消・**概要集原稿投稿**に必須 → durable に記録 (受理票メールを消さない + タスク管理側に pointer)。 講演申込期間後は登壇者変更・講演取消以外の修正を受け付けない。
- **概要集原稿は別締切** (申込締切の約 5 週後)。 各種手続ページから登録番号+パスワードで投稿。 申込完了時に概要集 follow-up タスクを必ず起票する。
- 申込時の「講演要旨」 欄 (200 字程度) は**プログラム編成専用・非公開** (概要集・プログラムに掲載されない)。 公開されるのは**題目・著者・所属** (講演概要集 Web 版 / PDF・Web プログラム / J-STAGE) → **集客は題目が勝負** ([giving-talks.md](giving-talks.md) の「タイトルは出席を決める唯一最重要の選択」)。

## 登壇件数の規則

- 一般講演の登壇 = **1 人 1 件** (シンポジウム・招待講演等の依頼講演を除く)。
- **例外 = 領域 13 (物理教育・物理学史・環境物理)**: 他領域で 1 件申込済でも、 領域 13 の 1 分野に限り**さらに 1 件**申込できる (= 専門 1 件 + 物理教育 1 件の 2 登壇が可能)。
- 領域 13 の 2 件目を申し込むときは**参加登録 (参加費) を「免除 (0 円)」 で選択** (form に明記あり) — 参加費は 1 件目で 1 回だけ払う。 二重払い注意。
- 口頭発表 = 講演 10 分 + 質疑 5 分 (2026 年次大会実測)。 ポスター = 120 分。

## form 各欄の落とし穴

- **キーワード欄は code (番号 or 英字半角大文字) を入力する** — 名称文字列 (例: 素粒子論領域の「Th」 と直接入力) は「コード登録に存在しません」 エラー。 欄は 6 個並ぶが**必要数は領域依存** (1〜3 個 + 任意追加)、 残りは空欄で可。 番号表は当年の公式キーワード一覧を見る。
- **著者・所属の記法** (概要集・プログラムにそのまま出る):
  - 上付き = `^...^`、 下付き = `_..._`。 表現できない場合のみ LaTeX (`!LaTeX$…$`)。
  - **登壇者印 = `^@^` を名前の直前** (= °印。 form 注記「登壇者を示す印は、登壇者が筆頭著者以外の場合のみつけてください」 — アルファベット順等で登壇者が筆頭でないときは必須)。
  - **所属区分記号 `^A^` `^B^` …** を各著者名の直後に付け、 所属欄の同記号と対応させる。 記号は「2 番目の所属以降」 が原則だが「1 番目につけても構いません」 (form 原文) → **全所属に付けて uniform にする**のが対応間違いを防ぐ (著者を分野慣習順 〔素粒子論系はアルファベット順〕 に並べ、 所属もその登場順に並べる)。
  - **連結は全角カンマ「，」** (半角カンマは form 例示に反して実運用では全角指定)。
  - 所属は**略称表記** (form 例: `東大理, 阪大工^A^, 広大総合科^B^, 高エ研^C^, 筑波大低温セ^D^`)。 外国機関は英字略称 (UCLA 等) がそのまま通る。 外国人著者名は Latin 表記が概要集通例。
- **半角カタカナ禁止** + **1 時間無操作で session 失効** (「次へ」 でエラー → 最初からログインし直し)。 入力データは手元に組み立ててから form を開く。
- **英語講演「希望する」 は別扱い**: 英語セッションにまとめられ、 日本語の同分野と**別会場・別日時**になる可能性 (form 注記)。 日本語で話すなら「希望しない」。
- **共著者の同意 checkbox** = 「共著者の同意を得ているものとみなす」 宣言。 チェック前に共著者の了解を取っておく (対面・chat での確認で可、 form は手段を指定しない)。
- 共著者の会員番号入力欄は**無い** (2026 年次大会実測) — 会員番号が要るのは申込者 (= 登壇者本人) のみ。 非会員の共著者もそのまま氏名を書ける。
- 概要 (要旨) は非公開・題目は公開という**非対称**があるので、 磨くべきは題目 > 要旨。 abstract に数式を書かない流儀は個人層の paper-style 側 (該当者のみ)。

## <a id="program-slot-lookup"></a>講演番号通知 → 講演時刻の導出 (申込の約 3.5 週後)

申込締切の約 3.5 週後に「講演番号通知 <登録番号>」 mail が届く (2026: 7/6 締切 → 7/30 通知)。 番号 = `<日><a|p><会場>-<順番>` (例 `16pE532-11` = 16 日 午後 E532 会場 11 番目)。 **時刻は番号だけでは決まらない** (= 休憩・取消・長い講演が混ざる) ので Web program で確定する:

1. program = `https://onsite.gakkai-web.net/jps/jps_search/<yyyy>a{u|s}/program/date/program<領域>.html#j<番号の会場部>` (au = 秋/年次、 領域 file 名は日程表 `timetable.html` の link から。 素粒子論 = `programsr`、 領域 13 = `program13`)。 会期の 7/31 前後に公開。
2. **session の `<ol>` 内 `<li>` を先頭から数える** (各 `（15分）` を積算、 `<div class="roundframe spaces">休憩 (hh:mm〜hh:mm)</div>` で時刻を jump)。 順番 -N = N 番目の `<li>`。 ⚠️ WebFetch の要約は **講演を 1 件落として番号をずらす**ことがある (2026 実測: 1 件欠落で 16:00 と誤報、 実 16:15) — 要約の時刻を採らず `curl` + 自分で数える。 持ち時間の規則 (講演 10 分 + 討論 5 分) と会場→建物の対応は前付け PDF (`jps.or.jp/activities/meetings/files/<yyyy>a_mae.pdf`、 p.9 前後 / 会場配置図)。
3. 確定したら **talks.yaml の date を会期初日から講演日に更新** + calendar に講演 slot の event (15 分) + events.yaml の talks 行に番号・時刻・event id — の 3 点を同 turn で。 同日の学内会議との重なりは calendar を並べた瞬間に見えるので、 その場で出欠を user に問う。 ⚠️ 番号通知の turn で「program 確定後に絞る」 と書いて止めない (program 公開は通知の翌日)。

## 発表内容の選定 (制度が形を決める部分)

- 「1 人 1 件 + 領域 13 例外」 により、 専門の演題を 2 本持っていても**同一領域では 1 本しか話せない**。 2 本目は (a) 領域 13 (教材・教育ネタがあれば) / (b) 別の研究会 (基研研究会等) に振り分ける、 が定石。
- タイトルは [giving-talks.md](giving-talks.md) 基準 (問い形 or 平叙断定、 聴衆の言葉、 「〜の解析」 型の dull を避ける) で書く。
