# 世界地図の図法ビューア (d3-geo + Natural Earth)

2026-09-05 に「イコールアース図法ビューア」 (正積図法を中央経線を動かして眺める単一 HTML 教材) を
1 日で作り、user の指摘で誤り・過剰を 10 回以上直した過程で得た知見。図法の数学、d3-geo の癖、
Natural Earth のデータ構造、UI の操作設計、web 一般の罠に分けて書く。個別 project の判断史は
その repo の DESIGN.md が正本で、ここは他 project でも再利用できる一般則だけ。

## 1. 図法の性質は「自称」でなく実測で守る {#measure-not-assert}

図法の定義一覧に `poleLine: false` (極は点) や 「正積」 の注記を**手で書いた**ら、その日のうちに
2 件が誤りだった (Equal Earth の極は点でなく赤道の 0.59 倍の**線**、Gall–Peters の歪みは
「高緯度が縦長」 でなく **低緯度が縦長・高緯度は横に潰れる**)。 メタデータは投影関数から測れるので、
書いた瞬間にテストで測る:

- **極が点か線か**: 極のすぐ下 (lat 89.99) と赤道で、経度方向の局所スケール比
  `(x(+δ, lat) − x(−δ, lat))` を比べる。比 > 0.05 なら線。両端 (±179.999°) の差で測ると
  断裂図法で lobe をまたいで誤判定するので、小幅 δ = 0.5° の局所比にする。
- **正積か**: 測地円 (半径 4.5° ≒ 500 km) を 5〜7 か所に置き、`geoPath.area / geoArea` の
  ばらつきが 1% 未満。断裂や外周をまたぐ位置は避ける (面積が跳ねる)。
- **経度回転で外郭が不変か** (下 §2 のキャッシュ前提): 経度を 5° 刻みで回して `path.bounds(Sphere)`
  の drift が 0.5 px 未満。
- **鏡像でなく回転か** (南を上): 既知の都市の投影座標が上下**と左右**の両方で入れ替わること。

「代表的な図法を全部」 と言われて d3-geo-projection にあるものを 15 個入れたら、user の
「本当に全部代表的?」 で 4 つ (エケルト第6・ワグナー第4・ボッグス・グード) を落とした。
ライブラリにあることは代表性の根拠にならない。教科書・地図帳・ソフトの既定に出るかで選ぶ。

## 2. 中央経線の回転と fit キャッシュ {#rotate-and-fit-cache}

- 中央経線は `projection.rotate([-lon, 0, 0])` だけで表す。反子午線での切断は d3-geo の標準
  クリップに任せ、ポリゴンを自前で分割しない。
- 擬円筒・円筒・楕円外周・擬円錐・方位のどれも、**経度回転では投影された球の外郭が合同**。
  だから図法ごとに `fitWidth` を 1 回だけ走らせて拡大率と高さをキャッシュでき、フレームごとの
  仕事は 「rotate 差替え + `d` の引き直し」 だけになる (地図の縦位置も微動しない)。
- 第 2 引数 (中心緯度) を使えるのは**方位図法だけ** (外郭が常に円)。擬円筒に入れると外郭が
  変形して前提が崩れる。第 3 引数 180° (南を上) は外郭が点対称なので全図法で無事。
- **断裂図法 (Goode 等) は回せない**: d3 の lobes は回転後の座標に固定なので、地球だけ回って
  断裂が大陸を切る。lobes を回転に追従させても地図の縁 (±180°) が必ずどこかの lobe を割り、
  割れた側の極が反対側へ来て外郭が枠外へ出る。任意の中央経線の Goode は well-defined でない
  (実物の地図も中央経線ごとに断裂を設計し直す)。「中央経線を動かす」 ビューアには入れない。

## 3. 拡大は viewBox の切り出し + 詳細度 2 段 {#zoom-viewbox-lod}

- 投影の scale を変えず、`viewBox` を `W/z × H/z` に切り出す。描画は不変で書き出し (同じ
  render 関数) も見えている範囲がそのまま出る。横は常に中央 (経度は回転で見る)、縦だけ `panY`。
- 操作: ホイール (トラックパッドのピンチ = ctrl+wheel) とスマホの 2 本指ピンチで拡大、拡大中の
  ドラッグは上下左右とも 「指の下の地図が付いてくる」 (内部では横 = 回転、縦 = 窓のずらし だが、
  user にこの区別を見せない)、ダブルクリック / ダブルタップで 1 倍。回転ドラッグの感度は
  `360° / zoom`。拡大中は `touch-action: none` (縦スワイプを地図が受ける)、1 倍では `pan-y`。
  地図上ではホイールがページスクロールを奪う = 地図が主役のページでのみ許される設計。
- **50m だけでは回せない** (国モードで 170 ms/frame、国なしで 65 ms)。動かしている間
  (commit=false) は 110m、止まった瞬間 (commit=true) と書き出しは 50m で描く。体感は
  「動かすと少し粗く、止まると精細」、ドラッグ中 20 ms/frame、静止時の描き直し 1 回 176 ms。
  単一 HTML は 110m のみ 175 KB → 50m + 110m 950 KB (gzip 305 KB)。

## 4. 国データ (Natural Earth admin_0、world-atlas 同梱) {#natural-earth-countries}

- **陸塊は国の merge で作る** (`topojson.merge`)。land-*.json と面積が 1e-3 以内で一致するので
  二重に持たない。国境は `topojson.mesh(topo, obj, (a, b) => a !== b)` (2 単位が接する弧のみ)。
- **国の識別 key は `properties.name`** (= NE の NAME)。ISO_N3 は 50m で属領が本国と同じ番号を
  持つ (Ashmore and Cartier = 036 = Australia) ので一意でない。name は 110m / 50m とも一意で
  110m ⊂ 50m。ISO id が無い単位 (Kosovo / Somaliland / N. Cyprus 等) も name で困らない。
- **日本語名は world-atlas に無い**。NE 本家の geojson
  (`nvkelso/natural-earth-vector`、`geojson/ne_50m_admin_0_countries.geojson`、public domain)
  の `NAME_JA` をビルド時に `{name: {en, ja, c, x, y}}` の小さな表 (241 単位で 18 KB) に落として
  同梱する。geojson 自体 (3 MB) はリポに入れない。`LABEL_X / LABEL_Y` は NE が用意している
  国名ラベル位置 — 重心だとチリやノルウェーで国の外に出る。
- **配色は `MAPCOLOR9` をデータのまま使う**。MAPCOLOR7 / 8 / 9 / 13 を比べると 9 だけが
  「隣接同色 1 組 (イスラエル–パレスチナ、既知例外) / グリーンランド = デンマークと同番号 /
  米・加・露・カザフが全部別」 を満たした。残る隣接同色は 「隣国に無い最小番号へ機械的に振り直す」
  という**一般規則**で解消する。**国ごとの手直しはしない** — 1 つ直すと次が出て連鎖する
  (パレット修正 → グリーンランド振り直し → デンマークに揃える → デンマークも振り直し … を経験)。
  「主権国で色を揃える」 も一律適用しない (NE の SOVEREIGNT では台湾→中国、パレスチナ→イスラエル、
  西サハラ→モロッコになり政治的主張を帯びる)。
- **パレットは番号が違えば見分けられる色にする**。砂色と小麦色のように近い 2 色を入れると、番号が
  違うロシアとカザフスタンが同色に見える。色相を等間隔に散らした低彩度 9 色。南極は白っぽく別扱い。
- **国名の描き込み規則**: 全単位に `<text>` を置き、「文字幅 ≤ 国の幅 × 0.95 + はみ出し許容」 のものだけ
  表示。文字は画面上で一定 (9 px、SVG 単位では `1/zoom`) なので、寄るほど小国の名前が現れる。
  国の幅は正積の性質から `sqrt(球面面積 × scale²)` (回転で不変、毎フレーム安い)。はみ出し許容は
  倍率 1 で 0、最大倍率で 200 px (寄るほど隣国は画面上で遠いので重ならない、最大倍率で全単位が出る)。
  縁取り (paint-order: stroke) で塗りに負けないようにし、文字は常に水平。
- hover / tap の国名は、塗り分けの path 自体を当たり判定にする (ティソー円と外郭は fill 無しで
  pointer を通す)。タップは 「4 px 未満で離した」 をドラッグ側で判定して発火する。

## 5. UI の判断 (user 指摘で確定したもの) {#ui-decisions}

- 地図が主役: 見出し → 地図 → 操作の順、リード文は置かない。
- ドラッグが PC でも効くなら **スライダーは二重化**なので置かない (数値入力 + プリセット + ドラッグ)。
- 図法の選択は**プルダウンでなくボタンの並び** (族ごとに 1 行、`aria-pressed` で選択表示)。
  14 個程度なら一覧で見えている方が比較しやすい。
- 「向き」 の操作 (南を上に) は 「回す」 と同じ行、レイヤ表示 (経緯線 / ティソー / 国) とは別の行。
- 要らないボタンは削る: 緯度プリセット (赤道 / 北極 / 南極)、陸地トグル、赤道・中央経線の強調線は
  すべて削除された。強調線は初版の 「裂け目」 教材の名残で、**趣旨が変わったら名残も消す**。
- 南を上 = **180° 回転**であって上下の鏡像ではない (鏡像は地理が左右逆の偽物)。ドラッグの向きは
  両軸とも反転させて 「指の下の点が付いてくる」 を保つ。
- 日本語 UI では英字を避ける (図法名はイコールアース / モルワイデ / エケルト第4 / ゴール・ピーターズ、
  経度は 西経90°)。例外はファイル形式名 (SVG / PNG) と脚注の出典。i18n は別ページでなく同一
  ファイル内の辞書 (`navigator.language` で初期判定、`?lang=` と切替ボタンで上書き、自動判定と
  同じ言語なら URL に書かない)。

## 6. web 一般の罠 (この project で踏んだもの) {#web-pitfalls}

- **`hidden` 属性は author の `display` に負ける**。`display: inline-flex` を当てた要素に
  `el.hidden = true` しても見える。`[hidden] { display: none !important; }` を reset に入れる。
- **`Number(null) === 0`**。`Number(params.get('lon'))` はキー不在で 0 になり既定値を潰す。
  既定が 0 の間は見えない潜在バグで、既定を変えた瞬間に露見した。`get()` が null なら先に弾く。
- **色 literal の同形異字**: `'#ececе6'` (キリル文字 е) は無効な色になり黒く塗られる。CSS / TS の
  hex literal は `^#[0-9a-fA-F]{6}$` で機械検査する価値がある。
- **headless / 非表示ペインでは `getBoundingClientRect()` が 0**。高さ 0 で割ると NaN が state と
  URL に流れ込む。`rect.height > 0` を確認し、NaN なら据え置く。
- 出典・標準値は書く前に一次資料で確認する: 「Patterson の Equal Earth 壁地図 3 版の中央経線は
  10°E / 90°W / 150°E」 と書いたが実際は **0° / 90°W / 150°E** (商品名 "Greenwich Meridian (0)")。
  もっともらしい数値ほど検索 1 回の価値がある。
